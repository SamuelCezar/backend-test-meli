# 📦 Backend Test - Samuel Chagas

## 📑 Sobre o projeto

Este projeto é um backend em Java 21 com Spring Boot que expõe uma API REST para consulta de itens, simulando o backend de uma página de produto no estilo Mercado Livre. Os dados são armazenados localmente em um arquivo JSON.

A documentação da API está disponível via Swagger/OpenAPI.

---

## 🚀 Como rodar o projeto

### ✅ Pré-requisitos:
- Java 21 instalado
- Gradle 8+ instalado (ou usar o wrapper incluso `./gradlew`)
- IDE compatível (IntelliJ IDEA recomendado) ou terminal
